Project: Retro-Industrial 'Telemetry Overlay' SVG Module

Description:
A standalone SVG component designed for indie game developers (extraction/survival genres). It features a high-contrast amber aesthetic, scanline effects, and status indicators.

How to use:
1. Open 'telemetry_overlay.svg' in any web browser or vector editor.
2. Incorporate the SVG into your UI layout as a modular HUD element.
3. The scanline effect is handled via an internal <pattern> and <filter>.

Intended Audience:
Game developers, UI designers, and artists looking for 'lo-fi' industrial aesthetics.

Unverified:
- Performance impact when scaled to 100+ instances (unlikely but possible).
- Compatibility with older SVG renderers that might struggle with complex filters.

Blockers:
None. The file is self-contained.
